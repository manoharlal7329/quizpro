Registration & Login

Account कैसे बनाएं

QuizPro में जुड़ना बिल्कुल आसान और secure है। कोई OTP झंझट नहीं — सिर्फ Mobile Number और Password से काम होता है।

  • 📱 Login Page खोलें — अपना 10-digit Mobile Number डालें जो पहले registered नहीं होना चाहिए।
  • 🔒 Password बनाएं — एक मजबूत password set करें। यह आपके account की security है।
  • ✅ Login हो जाएं — अगर account पहले से है तो same number और password डालें।
  • 🎯 Dashboard पर पहुंचें — तुरंत आपका personal dashboard खुल जाएगा जिसमें आपका wallet, sessions और referral link होगा।
  • 👤 Referral Link मिलेगा — Register होते ही आपको एक unique referral link मिलता है जिसे दोस्तों में share करके passive income कमाएं।
💡 Tip: अगर किसी ने आपको Refer किया है तो उनके referral link से ही register करें ताकि वे commission पाएं।

Wallet & Deposit

Points कैसे जोड़ें

Quiz में participate करने के लिए आपके Deposit Wallet में Points होने चाहिए। 1 Point = ₹1। Deposit process बिल्कुल instant है।

  • 💳 Wallet Section खोलें — Menu में "Account" या "Wallet" पर click करें।
  • 📷 QR Code Scan करें — PhonePe, Google Pay, Paytm, या BHIM UPI से हमारा QR scan करके payment करें।
  • 🔢 UTR Number डालें — Payment के बाद मिला 12-digit UTR/Transaction ID wallet में enter करें।
  • ⚡ Instant Credit — UTR enter करते ही points आपके Deposit Wallet में automatically आ जाते हैं।
⚠️ जरूरी बात: यहाँ 2 Wallets होते हैं — Deposit Wallet (quiz fees के लिए) और Winnings Wallet (जीती हुई राशि के लिए)। Deposit Wallet से quiz join होती है, Winnings Wallet से withdrawal होता है।

Quiz कैसे खेलें (The Arena)

Live Quiz Process

जब quiz start होती है तो यह एक real-time battle होती है। तेज़ी और accuracy दोनों जरूरी हैं। यहाँ luck का कोई role नहीं।

  • 📋 Session Join करें — Dashboard पर उपलब्ध upcoming sessions देखें। Join button press करके entry fee pay होती है।
  • ⏰ Quiz Start समय पर होती है — Scheduled time पर ही quiz automatically शुरू होती है। देर से आने पर questions miss हो सकते हैं।
  • ⏱️ 15-Second Timer — हर question के लिए सिर्फ 15 seconds मिलते हैं। Time खत्म होने पर auto-submit हो जाता है।
  • 🎯 Speed Bonus — जितना जल्दी सही answer दें, उतने ज़्यादा score points मिलते हैं। Accuracy + Speed दोनों जरूरी।
  • ❌ गलत Answer = 0 Points — गलत answer पर कोई negative marking नहीं, पर score भी नहीं मिलेगा।
  • 🏆 Real-Time Leaderboard — Quiz खत्म होते ही final ranking दिखती है और prizes automatically distribute हो जाते हैं।
